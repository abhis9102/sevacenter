# SevaSetu

Multi-tenant SaaS for Indian temples and religious trusts — a "Planning Center for temples."
Each trust self-registers and gets its own branded space (`yourtemple.sevasetu.app`) to manage
devotees, collect donations, run events, and publish announcements.

**Status:** design / brainstorm (started 2026-10-02). Building from scratch.

> This is also the working project for Abhi's DevSecOps / Cloud / AppSec training. Three roles,
> one person orchestrating: **Dev** (coding agents) write code, **AppSec** (Abhi) secures every
> stage, **DevOps** (agents + Abhi) runs CI/CD and AWS. See `docs/roles-and-teams.md`.
>
> Clean-room analog built from Planning Center's *public product shape* only. Nothing from any
> prior security testing of the real Planning Center touches this project.
